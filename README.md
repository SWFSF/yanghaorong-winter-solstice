# 杨皓蓉冬至祝福网站

这是一个可直接静态部署的单页祝福网站。页面使用 Canvas 实时绘制冬夜、飞雪、冰晶和可持续回冻的霜层；开场包含约 15 秒的逐字冰封仪式，八枚雪光分别对应八封冬至冬笺。

## 本地运行

直接双击 `index.html` 即可浏览主要效果。为了获得与线上环境一致的浏览器行为，也可以在当前目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 操作

- 点击“擦开”开始逐字冰封、霜层聚集和标题结晶的动画。
- 在开场动画中轻触画面或点击“轻触跳过”可以提前进入雪光星图。
- 进入星图后，按住霜面拖动可以擦出窗口，擦开的区域会在约 4.5 秒后重新结霜。
- 点击任意雪光打开祝福，使用“上一封”“下一封”继续阅读。
- 点击“回到星图”收藏进度并继续探索。
- 八封全部阅读后，可以“从头再看”或“重新覆霜”。
- 右上角可以开启或关闭原站背景音乐和冰晶轻响。

页面每次刷新都会重新开始，不保存阅读记录，也不收集任何访问数据。

背景音乐通过 `<audio>` 元素引用原参考站的远程 `1.mp3`，未复制到公开仓库。若远程音轨不可用，页面会自动保留无背景音乐的冰晶轻响版本。
